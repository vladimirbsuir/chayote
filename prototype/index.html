4 · Empty and error states

Every state explains the cause, not just the fact. No illustrations, no emoji. The dashed panel is the first-launch experience — no folders, no tags, no seeding.
No notes yet
Your notes are stored on this device and never leave it.
Nothing pinned
Pin a note with Ctrl D to keep it at the top of the list.
No results for “roadmap”
Search covers titles and the full text of every note.
Nothing here
This folder is empty.
Trash is empty
Deleted notes stay in the trash until you empty it.
Couldn't save — retrying
Your text is safe on this device. Retrying automatically.

5 · Settings dialog

Six accent presets plus a custom colour. Settings live in the Tauri store, never in the notes database. The swatch ring is the only selected state — it is never colour alone.

Notes for review

Ctrl B / I / S / E bold, italic, strike, code · Ctrl N new note · Ctrl D pin · Ctrl F search
Formatting toolbar above the editor content on desktop, below the editor bar on Android — every shortcut above has a visible button there. 32 px targets on desktop, 44 px on Android, horizontally scrollable.
Icon sizes: 16 inline in text, 18 controls, 20 section headers, 24 mobile top bar. Stroke steps 2, 2, 1.75, 1.5 to hold optical weight.
Icons inherit currentColor and are never given a hard-coded colour. An icon never carries meaning alone — the pinned note, the empty state, and the error state all have text.
Note list is not drag-reorderable in v1 (ADR-011). Folder tree is.
The editor is not real. Typography, spacing, token values, and icon weight are the deliverable here.
